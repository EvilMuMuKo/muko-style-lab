# MuKo Style Lab R1 · 同一套房子，四种材质（1.0.0）

一句话：**不动一间墙、不挪一件家具**，只换材质、颜色、灯光与少量几何点缀，检验「包豪斯 × 日系」这条线能推到哪一档。

R1 是初版，没有历史覆盖层可继承。数据来自 muko-home R7（17.0.0）导出的模型：8 个房间多边形 + 104 件家具 + 15 个门窗洞口，抽成本仓库的 `src/plan.json`。

## 做了什么

- **一套几何**：8 个空间（影音客房、卫浴、主卧、半开放厨房、阅读·家庭水吧、入户走廊、可变客厅、家务阳台）按 R7 的平面坐标 1:1 摆出来，墙厚 140mm、层高 2.70m，门窗按洞口开在墙上。
- **四套材质**：每套定义 21 个颜色槽、5 条地面配方（木地板 / 厨房 / 水吧 / 卫浴 / 阳台）、灯光增益与一条"风险"文案。
- **程序生成贴图**：棋盘格、木纹、水磨石、100mm 小方砖、招牌字，全部运行时画在 canvas 上，不引入图片资源，一次风格切换不增加网络请求。
- **可交接的界面**：空间/镜头下拉、复位、导出 PNG、漫游（WASD + Q/E + 拖拽、圆半径碰撞）、日夜三档、深链参数。
- **4 项冒烟测试**：风格与空间枚举、切换风格改变实际像素、日夜与镜头联动、复位/漫游/无控制台错误。

## 四套风格为什么这样定

| # | 风格 | 分工 | 关键数值 |
|---|---|---|---|
| 01 | 包豪斯·原教旨 | 面全白，颜色只做构件 | 墙 `#F3F1EC`、柜 `#F4F2ED`、台面 `#232326`、三原色 `#D2321E / #1B4C8C / #F2B300` |
| 02 | 中古包豪斯 | 深蓝砖压半墙，木色回暖 | 砖 `#23405E`（100mm）、柜 `#7A4E31`、棋盘 `#EDE6D8 × #C87941`（250mm） |
| 03 | 侘寂 × 包豪斯线 | 米白 + 浅橡木，只留墨线与一点群青 | 墙 `#E8E2D6`、木 `#C9A882`、墨 `#1A1C1E`、群青 `#2A4A6B` |
| 04 | 多巴胺孟菲斯 | 色块当构件，黑白线收边 | 下柜 `#2D6BE0`、吊柜 `#F5C518`、砖 `#F28DA8`、棋盘 `#FFFFFF × #111111`（400mm） |

四套共用同一套"日系底 + 包豪斯线"的骨架：木色地板、细黑框、拉丝金属、亚光面。差别只在**颜色落在哪里、落多少**。

## 这轮实测

2026-10-21：

- `npm run build` 通过（tsc --noEmit + vite build），产物 `dist/` 约 580KB JS（gzip ~150KB）。
- 本机 Chrome（headless，`CHROMIUM_PATH`）跑 `npx playwright test`：**4 passed / 7.8s**；CI（软件光栅化，2 分片）**32s / 37s** 通过并部署。
- 逐风格截图复核 20 张（5 机位 × 4 风格），修复了五处真实缺陷：
  1. 厨房滑门被建成实心黑板 → 改为"四边细框 + 玻璃"；
  2. "开启"的滑扇沿 x 轴凸出 140mm 挡在镜头前 → 改为沿 z 轴滑到相邻扇背后；
  3. 嵌入式冰箱与高柜前脸共面导致 z-fighting 花屏 → 冰箱整体前移 60mm 并补双竖把手；
  4. 换日夜档会重建全部 13 张 canvas 纹理 → 拆出 `applyPhase()`，只改灯光与自发光；
  5. 每帧无条件渲染，在 CI 的 1fps 软件光栅化下点击迟迟落不下来 → 改为**按需渲染**（相机补间、过渡、漫游或显式 dirty 才出帧），相机过渡也从逐帧阻尼改成 **620ms 时间驱动**。
- 关闭实时阴影贴图：薄墙 + 柜体的掠射角自阴影会产生成片噪点，见下文边界。

## 边界

- **几何不等于施工**：尺寸来自 muko-home 的虚拟模型，该仓库自述"未现场复尺，不能用于施工"，本仓库不重测，所以同样不能。
- **无实时阴影 / 无 AO**：`renderer.shadowMap.enabled = false`。这是为"看材质与配色"做的取舍，不是性能妥协；代价是家具缺少接触阴影，画面偏平。
- **材质是近似**：砖的尺寸、缝宽、釉面、防滑、吸水率、阳角收口、勾缝剂均未定；棋盘格只是比例示意。
- **家具是体块**：柜内分格、把手规格、五金承载、软包坐感均未建模；`plan.json` 的坐标不能直接当家具下单尺寸。
- **灯光不是照度**：日/夜/观影三档只调亮度与色温，没有物理光照计算，不作为照度或眩光验收。
- **真机 NOT RUN**：只在桌面 Chrome 上跑过；移动端布局做了响应式，但真机帧率与触控漫游未验证。
- **燃气与烟道**：R1 不涉及任何机电结论。
